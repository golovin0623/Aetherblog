## 结论速览

**定位（§1）**：创作团队 + 常驻智能体的协作信道，无陌生人社交。
不做好友申请链路 —— 联系人 = `/members` + `/agents` 聚合，零新后端。
智能体是同席者：可 @、可私聊、回复以 ink-bleed 流式书写（签名时刻 #5 延伸）。

**信息架构（§2）**：RAIL(64px) · LIST(296px) · THREAD(主舞台) · INFO(270px 按需)；
≤860px 退化为 LIST ↔ THREAD 单栏栈式，与现 `mobileView` 状态机同构。

**表情三层（§4）**：emoji 字符（零改动）→ 消息回应（P1 新表）→
「星灵 Aeti」贴纸包（P0：`IMAGE + attachmentMeta.sticker` 协议，零后端）。

**提示五级（§6）**：气泡回执 → 会话徽标 → 导航总数 → 页内 Toast → 系统级；
@我 是唯一穿透免打扰的信号。
