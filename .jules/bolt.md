## 2025-05-08 - useCallback vs useMemo impact on fast string/array operations
**Learning:** During review of wrapping inline `.slice()` or string fallback assignments in `useMemo` specifically to prevent re-evaluations during hover state re-renders (like in `useSpotlightEffect`), it was identified that wrapping extremely cheap operations (such as `Array.slice(0, 3)` or `||` logic) in `useMemo` is a React anti-pattern. While it prevents redundant execution, the overhead of hook invocation, closure creation, and dependency array comparison can be slower and consume more memory than the raw operations themselves.
**Action:** Do not use `useMemo` to wrap microscopic, ultra-fast array or string computations unless they demonstrably become bottlenecks or are used as dependencies in `useEffect` (where referential equality is crucial). Focus optimization efforts on actual performance bottlenecks, avoiding useless micro-optimizations that clutter code.
