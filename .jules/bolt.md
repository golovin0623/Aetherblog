## 2024-06-06 - [Avoid Hook Overhead for Trivial Calculations in High-Frequency Renders]
**Learning:** In components subject to high-frequency re-renders (such as `FeaturedPost` using `useSpotlightEffect` which updates state on mouse events), wrapping trivial operations like simple string slicing and boolean fallbacks in `useMemo` is a micro-optimization anti-pattern. The overhead of dependency array allocation and shallow comparison in React hooks far exceeds the minor garbage collection savings from caching trivial primitives.
**Action:** Always measure and compare the cost of memoization against the operation itself. Never use `useMemo` for basic `String.slice()`, concatenations, or `||` fallbacks. Only reserve `useMemo` for computationally expensive tasks like complex Regex operations, heavy loops, or object creation passed to memoized children.
