## 2025-07-15 - Dynamic IDs for Shared Form Component Helper Text
**Learning:** When building highly reusable, primitive form elements (like `Input` or `Textarea` inside `packages/ui`), relying solely on hardcoded IDs or omitting `aria-describedby` results in broken accessibility contexts if the form element needs to render error/helper messages dynamically. Furthermore, since these components can be instantiated multiple times on the same page, static IDs will cause invalid HTML and confuse screen readers.
**Action:** Always use `React.useId()` inside generic form components to dynamically generate unique IDs for helper/error text containers. Ensure the `<input>` or `<textarea>` element's `aria-describedby` safely merges external props with the dynamically generated ID (e.g., using `[props['aria-describedby'], helperId].filter(Boolean).join(' ')`), and conditionally map `aria-invalid` to the `error` state.
