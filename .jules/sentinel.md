## 2025-02-28 - Path Traversal bypass in Reverse Proxies (Echo 4.x)
**Vulnerability:** Reverse proxies in Echo 4.x attempting to prevent Path Traversal by extracting sub-paths using `c.Request().URL.EscapedPath()` and `strings.TrimPrefix` can be bypassed. Maliciously crafted URLs with matrix parameters, unexpected `%2F`, or double slashes may cause the `TrimPrefix` approach to misalign with Echo's router mapping, allowing subsequent `..` validation checks to be subverted.
**Learning:** `c.Request().URL.EscapedPath()` is not always aligned with Echo's routing logic. In Echo 4.x, `c.Param("*")` intrinsically preserves URI encoding while correctly extracting the matched segment.
**Prevention:** In Go/Echo reverse proxy handlers, avoid manually extracting sub-paths via `EscapedPath()` and `TrimPrefix()`. Instead, consistently use `c.Param("*")`. Note that `c.Param("*")` omits the leading slash, so conditionally prepend it (e.g., `if param != "" { subPath = "/" + param }`) before passing the raw sub-path down to backend services.
